# Day 01 Notes

Repository = папка/проект на GitHub, где хранятся все файлы
Commit = сохранение изменений с описанием, что было сделано
Git = система контроля версий (отслеживает изменения в файлах)
GitHub = сайт, где хранятся репозитории
Workflow = цепочка действий в n8n (автоматизация)
Node = один блок/шаг в workflow
Trigger = то, что запускает workflow (например, кнопка, webhook, расписание)
API = способ, которым программы общаются друг с другом
Webhook = специальный адрес, на который можно отправлять данные, чтобы запустить workflow
JSON = формат данных (похож на словарь), который чаще всего используют API
